# Questions

This is the main entry point for question-driven investigations. Each subdirectory should be named after a specific, durable question—for example, `how-did-navier-stokes-emerge` or `what-makes-a-numerical-scheme-stable`.

A question page should normally include:

1. the question and why it matters;
2. a concise answer or current working answer;
3. the scope, definitions, and assumptions;
4. historical and conceptual context;
5. derivations, experiments, or code when they improve the answer;
6. verification or counterexamples;
7. unresolved questions and references.

Organize around the question, not the university department that might teach it. Cross-link supporting work in `people-and-ideas/`, `equation-to-code/`, `builds/`, and `maps/` instead of duplicating it.

Before marking an investigation complete, identify its proof of work: the smallest set of sources, derivations, experiments, code, or verification results that makes the answer inspectable.
