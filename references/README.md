# References

This area holds shared bibliographies, source notes, dataset records, notation conventions, and citation guidance.

For each source, record enough information to locate it again: author, title, publication, year, edition or version, stable link or DOI, access date when relevant, and the specific claim or project it supports.

Prefer links and original notes over storing copyrighted source files. Distinguish primary sources, secondary scholarship, textbooks, standards, datasets, and informal explanations; a source's role matters as much as its citation.
