# 传热学 → 数值方法：问题驱动路线

更新：2026-09-23。采用用户指定的 fast.ai 式 top-down 学法；不是 fast.ai 官方课程。
已有基础：会 Python，了解基础机器学习；Class、深度学习不作为本路线先修要求。

每课顺序：具体问题 → 先跑通并观察 → 改一个参数 → 拆解物理假设 → 方程与代码对应 → 验证 → 自己解释。
数学按问题需要补充，函数和循环足够时不引入 Class。先把传热问题做完整，再深入数值算法。

| 待选题 | 墙体加厚一倍，热损失会减半吗？ | 稳态导热、热阻与边界条件 | 代数、单位检查 |

路线可被用户的新问题重新排序；不以读完整本教材为开课前提。
