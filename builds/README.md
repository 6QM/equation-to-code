# Builds

Builds are integrated artifacts that go beyond a single derivation or experiment: solvers, libraries, interactive demonstrations, visual tools, or end-to-end engineering projects.

Each build should state the problem it solves, its intended users, its maturity, and how to run it. Include a small reproducible example and distinguish validated capabilities from planned ones.

Supporting derivations belong in `questions/` or `equation-to-code/` and should be linked here rather than copied.
